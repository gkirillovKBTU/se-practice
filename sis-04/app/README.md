# Smart Campus Room Availability

A React and TypeScript application that filters a fictional room catalog by capacity and required equipment, then checks the selected room's availability.

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

Open the local address printed by Vite.

## Test

```bash
npx vitest run
```

The suite covers AC1–AC5, F1–F5, boundary cases B1–B6, and an integration path.
