# Smart Campus Room Availability Checker

This is a client-only React and TypeScript exercise for one fictional room. `src/App.tsx` owns
the form and feedback, `src/booking.ts` owns the availability policy, and
`src/booking.test.ts` verifies AC1-AC5. Styling and responsive layout live in `src/styles.css`.

Use `npm run dev` for the page, `npm run test:unit` for tests, `npm run lint` for static checks,
and `npm run build` for a production build. No login, database, real timetable, or deployment is
part of this project.
